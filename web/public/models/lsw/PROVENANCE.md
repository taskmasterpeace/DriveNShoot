# LSW bodies: provenance and licence

These files are the near-person bodies DSOA borrows from Robert's own game, Living Superweapon (`D:/lsw`).
They are generated by `web/tools/lsw-bodies-ingest.mjs` and used by `web/src/systems/lswbodies.js`.

| File | What it is |
| --- | --- |
| `superhero-male.bin` | Quaternius **Superhero_Male_FullBody**: body, eyes and eyebrows merged into one skinned geometry (positions, normals, 4 bone weights, a part id, 16-bit indices) |
| `superhero-female.bin` | Quaternius **Superhero_Female_FullBody**, the same layout |
| `bodies.json` | the byte layout, sha256 of each `.bin`, and the 65 bind-pose joints (name, parent, position in metres) |
| `LICENSE-CC0.txt` | the CC0 1.0 Universal legal code, copied from `D:/lsw/assets-src/quaternius/LICENSE.txt` |

## Not shipped, and why
DSOA's own pose solver drives every pose (the plan's point 1), so no animation clip is needed: the fingers' grip and the
idle breath are procedural. None of LSW's motion packs is copied. Their licences, read from each `manifest.json`:
| Pack | Licence | Could it ship? |
| --- | --- | --- |
| `motion.hero-ual`, `motion.hero-ual2` (Quaternius Universal Animation Library) | CC0-1.0 | yes, if ever needed |
| `motion.cmu-walk-02` (CMU Graphics Lab mocap) | LicenseRef-CMU-Mocap (free use; CMU asks for credit) | only with CMU's notice alongside |
| `motion.fab-close-combat` v1-v3 (a Fab marketplace pack) | **Proprietary-Internal** | **no** - not redistributable in this repo |

The eye texture `T_Eye_Brown.png` (CC0, same Quaternius pack) is not needed: eyes are painted by the shader.
