# DIVIDED STATES OF AMERICA — Agent Guide

A top-down open-world engine (GTA-1/2 camera, 3D rendering) set in a post-apocalyptic United States: the ruins of Phoenix, Arizona, and I-10 streamed out of it, west to Los Angeles and east to El Paso. It's built to be **driven, tested and extended by AI agents** from a shell, with no clicking and no reading engine internals.

- **Stack:** three.js 0.170 + Vite. Plain ES modules, no framework, no asset downloads (every texture, portrait, flag and sound is generated in code).
- **Features:** on foot plus driving, pistol/SMG/shotgun, an NPC dialogue system with portraits, a day/night cycle, 7 weather types, gore (blood spray, pools, trails, gibs), enterable buildings (the roof cuts away) with swinging doors (shove one open into someone and they go down), locked doors you kick in or shoot open, and windows that crack, shatter, get climbed through or boarded up, a wanted level, quests, the Whaler harpoon, traffic and raider AI.

## The Building Lab (making places fast)

**http://localhost:3141/lab.html** (the same dev server): pick a kind (house ... strip mall, plus office floor, school
wing, motel, warehouse with mezzanine, hospital ward), set width, depth, front and seed, and see the plan from the real
`floorplan()` with typed rooms in metres beside the 3D building exactly as `world/ring.js geo()` builds it. Edit by hand
(drag walls and doorways, split rooms, carve halls, retype rooms, add a storey: its stairs placed by the storeys rules),
every edit proved live by the ring's own NavProbe (unreachable rooms, sealed floor, blocked doorways and stair feet in
red), then export a row `data/authored.js` loads - or stand it in the running game: `author row=<json> x= z=` (or
`lot=`, `sample=office2`; `remove=<id>`). Spec and numbers: **docs/design/WEB_BUILDING_LAB.md**. URL states for agents
and screenshots: `lab.html?kind=offices&seed=131&storey=copy&floor=1&roof=0` (also `w d front zone units storeys cam
demo=seal tool`); `window.LAB` in the page (set, addStorey, commit, ED, proof, row, load, draw).

## THE WORLD FORGE (editing the world; docs/design/WEB_FORGE.md)

**http://localhost:3141/forge.html**: the unified world editor on the game's own dev server. Every tab writes DATA ROWS
(field-preserving: what it does not know rides through untouched), validates them with the engine's own code and, with
LIVE on, pushes them into the attached game tab so only the chunks they reach are laid out again. MAP edits
`src/data/usmap.json` (the national map: roads, rails, rivers, towns and holdouts, exits, slots; atlas sites and the 50
bases as layers; dead ends, orphans, unbridged crossings, WorldIndex's warnings). BRUSH paints `src/data/brush.json`
(forest, canopy, brush, ruin, rad) that `world/brush.js` feeds the chunk generator: thick pine, oak and cypress woods,
hot zones. TERRAIN shows the baked land and the I-10 profile and flips `terrain on=` live. BUILDING and OBSERVE mount the
Lab and the observer. Per-tab undo/redo (`Ctrl Z`/`Ctrl Y`), a command palette (`Ctrl K`), HOW TO USE drawers (`?`), health
dots. Agent parity: `forge`, `forgePatch` (any row ops; returns the inverse), `forgePush`, `mapEdit`, `mapCheck`, `brush`,
`brushPaint`. Server routes `/forge/*` live in `tools/forge-io.mjs`; `node tools/forge-shots.mjs` screenshots it
(`window.FORGE` drives the page). `usmap.json` rows the forge wrote survive `tools/import-usmap.mjs` (`meta.forge.edits`).

## 60-second quickstart (for agents)

```bash
npm install
npm run agent &                  # dev server + headless browser; prints READY (or open http://localhost:3141/?agent=1 yourself)
node tools/dl.mjs status         # {"connected": true}
node tools/dl.mjs selftest       # 140/140 engine checks (only=<text> runs a subset while you work)
node tools/dl.mjs state          # everything about the current moment
node tools/dl.mjs help           # every command, args, description
```

Every command is **JSON in, JSON out**. Commands never throw. A failure comes back as `{ "ok": false, "error": "...", "hint": "..." }`, and the hint tells you the right args.

```bash
node tools/dl.mjs teleport x=0 z=-70
node tools/dl.mjs spawn kind=raider count=5 x=0 z=-110 angry=true
node tools/dl.mjs give weapon=smg smg=128 && node tools/dl.mjs equip weapon=smg
node tools/dl.mjs fire id=hostile shots=20          # nearest enemy, re-acquired every shot
node tools/dl.mjs step seconds=3                    # advance sim; returns state + events
node tools/dl.mjs screenshot --out shot.jpg         # LOOK at the result
node tools/dl.mjs events type=kill
```

Several commands in one round trip (stops at the first failure):

```bash
node tools/dl.mjs batch '[{"cmd":"setTime","args":{"hour":23}},{"cmd":"setWeather","args":{"key":"STORM","instant":true}},{"cmd":"step","args":{"seconds":2}}]'
```

Raw HTTP, if you'd rather skip the CLI:

```bash
curl -s localhost:3141/agent/cmd -H 'content-type: application/json' -d '{"cmd":"state"}'
curl -s "localhost:3141/agent/cmd?cmd=teleport&x=0&z=0"
```

In the browser console, or inside scenario code: `await DL.call('state')`, or `DL.bind()` and then `await DL.teleport({x:0,z:0})`.

**Full command reference:** [docs/COMMANDS.md](docs/COMMANDS.md), generated from the code. Regenerate it with `node tools/gen-commands.mjs` after adding commands.

## The observer, the recorder and the three multipliers (docs/design/WEB_OBSERVER.md)

**For a person:** open `http://localhost:<port>/observe.html` in its own window beside the game (a hidden tab's frames
stop) or beside the headless harness. It attaches to the tab the bridge drives (the chip in the bar picks another:
`/agent/status` lists them as `tabList`, `?tab=<id>` pins one) and shows: the map (wheel zoom from all of I-10 to a
doorway, drag, people in faction colour with real flags, vehicles, doors, event ripples), the WIRE (kills, deeds,
witnesses, rumours, the director, roles, trades, deaths; filterable), a card for whoever you click (AI state, target,
needs, memory of you, inventory, FOLLOW, a live CAM), PERF, FACTIONS, CENSUS and a CONTROL LOG. The bar's buttons and
modals (pause, step, time, weather, spawn, give, god, director events, teleport, record) and the map's right-click menu
are each one COMMANDS row. REPLAY opens any recorded session (the live ring or `web/sessions/*.json`) with a scrubber,
the keys held at that moment, and WENT / FOUGHT / DIED heatmaps (one session or all of them).

**The feed** never goes through the command queue: while somebody watches, the game tab pushes a frame every 200 ms
(`/agent/feed`), so the map stays live while an agent runs `selftest` or a scenario in the same tab.

**The recorder** (`record`, `session`, `replay`): a 4 Hz ring of the player's position, heading, hp, speed, flags and
keys plus every event, on the game clock; a person's tab writes it to `web/sessions/<id>.json` every 2 minutes
(`record save=true` any time). `replay at=<t>` gives where they were; `replay heat=went|fought|died` the hot cells.
It costs a frame nothing measurable (`scenario name=recorder-cost`).

| Multiplier | Instead of | Example |
|---|---|---|
| `look` | `screenshot` + `state` + `query` x2 + `doors`, then guessing which dot is who | `node tools/dl.mjs look --out a.jpg` → the image, a caption, every person in frame (name, faction, flag, state, hp, hostile, target, pixel position), vehicles, doors, containers |
| `snap` + `diff` | dumping state twice and diffing JSON by hand | `snap name=before` … `diff from=before` → who died/appeared/moved/got hurt, vehicles, doors, your hp/cash/pack, standings, roles, quests, events by type, a one-line summary |
| `watch` | a `step` + `events since=` + filter loop | `watch type=kill id=okonkwo seconds=30` (stepped) · `node tools/dl.mjs watch type=kill,downed --follow` (streams lines) |

Also: `observe` (the observer's frame as JSON), `person id=` (one person's card), `heal id=`, `mapBase`, `mapTiles`.
Address one tab from the shell with `--tab <id>` (or `DL_TAB`; the MCP server reads `DL_TAB` too).
`node tools/observer-shots.mjs --step <name> "<js>" <ms>` screenshots the observer page from a private headless Chrome.

**Honest by default:** `talk` and `enterVehicle` require you to actually be there (within about 4 m), and the error tells you where the target is (`moveTo id=... first`). Pass `force=true` only in tests. Named characters dropped by raiders or traffic are downed and back on their feet after 45 s (you get a `downed` event with the countdown). If *you* kill one, they stay dead, except characters marked `essential: true` (the quest-giving sheriff and Doc Reyes), who always come back so the story can't dead-end. Killing them still earns wanted stars. Mark your own quest givers `essential` in content packs.

Blocking commands return early with an `interrupted` reason rather than failing silently. Every command has a wall-clock watchdog (`budget=<s>`, default 90 s; scenarios get 900 s) and yields to the event loop while it runs, so the page and bridge never hang.

## Look & feel

- **People:** instanced low-poly humans (rounded torso, hips, sphere head with a readable face, capsule limbs with hands and boots), 5 hat/hair styles (short, cap, cowboy, mohawk, wrap) and 3 gear styles (vest, backpack, spiked raider pads) picked per faction. They aim two-handed, sway when walking, lean when running. Around 19 draw calls cover all 160 people.
- **Vehicles:** beveled bodies, cylinder wheels with hubs, tinted glass, ram spikes and a harpoon turret on the Whaler, head and tail lights. Paint chars as the vehicle takes damage, it smokes at low HP, burns for 4 s, then explodes.
- **Gore:** directional blood spray, growing pools, exit splatter, drip trails from the wounded, clothes that soak through with damage, bloody footprints after walking through a pool, gibs on run-overs and explosions, head pops (explosion, point-blank shotgun, harpoon yank) with an arterial neck spray, and a dragged-body trail on the harpoon.
- **Interiors (`systems/interiors.js`):** every enterable building hangs real door leaves (a shop's double front door, single back and inner doors; wood or steel) that swing when walked or driven into, keep their angle, and stop sight and rounds while near closed. Shoved open fast, a leaf knocks whoever is behind it flat on their back for a moment (`doorBash`). Locked doors wear a rust-orange chain across the frame. Windows are notches down to a knee-high sill with clear glass on the car glass's crack shader: rounds crack it, then shatter it into a rim of shards and glitter on the floor; boards are crooked planks on the side they were nailed from. The infected claw at glass and boards and batter locked doors. One InstancedMesh each for leaves (plus chains), panes and boards (+3 draw calls); only doors near the player are simulated.
- **Military (`systems/bases.js`, rows in `data/bases.js`):** OUTPOST NINE is one merged mesh (walls, floors, towers, furniture, props), one roof batch (each building's roof hides when you walk in), one alpha-tested chain-link mesh, and two additive light batches (searchlight pools and beams, floodlight pools) hidden by day and culled when the base is out of view: 68-69 draw calls in the yard by day, 71-74 at night, and 1 extra (the rifle model) anywhere else. Razor wire coiled along the fence, towers with an open deck so you can see the sentry, a burned-out helicopter on the helipad, sandbags, jersey barriers, the old flag. The soldiers wear helmets, vests and faded olive and tan, and carry the SERVICE RIFLE; the PATROL TRUCK has a roof ring with a standing gunner, the ARMORED CARRIER eight wheels, a turret hatch and armoured vision slits.
- **Sound (synthesized, no files):** stereo-panned by screen position, distance falloff that also dulls the high end, per-weapon reports, near-miss whizzes, ricochets, footsteps by surface (sand/road/floor), a 5-gear engine, rain and wind beds, thunder, crashes, skids, horns. `perf.audio.played` counts what was played, so headless runs can verify sound.

## Robustness features for agents

- **The game never freezes on a bug:** the real-time loop and `step` catch per-frame exceptions, keep running, and record them in `perf.runtimeErrors` and as `error` events. `selftest` fails if any occurred.
- **Compile errors are visible:** a file that fails to parse shows up in `status.recentErrors` with file:line:col, even though the page can't load it.

- **One active tab:** if several game tabs are open, the newest one gets the commands and the rest stand by (`status` shows `tabs` and `activeTab`).
- **After a long command, let the tab poll again:** a tab running `selftest` does not poll the bridge, so 25 s in `status` shows `tabs: 0`, and a command sent the moment the long one returns can get 503 "no game tab connected". A fresh-page reload lost that way means the next selftest runs on the same page (on a reused page the trade check can meet a shelf restocked for a later day). Wait until `status` shows `lastPollMsAgo` under a few seconds, reload, and check the page is fresh (`game.time` under ~30, `game.society.day` 0) before the next battery.
- **Page errors are reported:** syntax errors and crashes in the page are forwarded to the bridge and appear in `status.recentErrors` and in 503 replies, so a broken edit never shows up as just "no game tab".
- **Code edits keep your place:** a full-page reload in dev snapshots and restores the game state (position, inventory, quests, time, every entity).
- **`?scenario=<name>` in the URL** runs a scenario on load. `?agent=1` skips the title screen.

## Player QOL (also exposed to agents)

Doors and windows on **E** (when nobody to talk to and no car is in reach): kick a door (a locked one takes 2-3), smash glass, tap to climb through a broken window or hold to board it up (hold again on the boards' side to pull them off); sprint into a door to bash it open, dive into a window to go through it. Objective tracker with GPS distance, gold route on the minimap, full map (**M**) with click-to-waypoint, pause menu (**Esc/P**) with difficulty (story/normal/hard), volume, render scale, shadows, auto-reload, aim assist and perf overlay (all saved), quick save/load (**F5/F9**), hit and kill markers on the reticle, a highlight ring under whatever **E/F** will act on, out-of-combat health regen to 60%, vehicles that burn for 4 s before exploding, respawn on the clinic doorstep. **Roles** (docs/design/WEB_ROLES.md): stitched tapes on the status plate, beside the street sign, show what the world calls you (chevrons for rumoured, known, renowned), a toast when one is earned, rises, fades or is suspended, the pause menu's WHAT THEY CALL YOU lists each with its renown, why and what it opens, and the PACK header says KNOWN AS ...; talk (**E**) to someone hurt with a med item on you and the first choice patches them up.

## Coordinates & conventions

- Units are metres. The ground is the XZ plane, +Y is up. **+x = east (screen right), +z = south (screen down).** The camera looks straight down with north at the top.
- Heading/facing is in radians: `0` faces +z (screen down) and `π` faces −z (screen up). Forward is `(sin h, cos h)`.
- For `drive`, `steer` +1 turns the car to ITS left (counter-clockwise on screen) and −1 to its right; `throttle` −1 brakes, then reverses (to the row's `reverse` speed). The keyboard's A/D are screen-true instead: A turns the nose toward the left of the screen whichever way the car points, latched while held (`vehicles.js` DRIVING.screenSteer, `screenSteer()`; `steerToward()` for a stick). A car you get out of brakes to a stop (it no longer rolls away out of reach).
- **Walkable vehicles** (`deck`; docs/design/WEB_WALK_VEHICLES.md): a pickup's bed, a van's cargo box and an RV's coach are floors that ride with the vehicle. E climbs into a bed or steps in a door (walking into a door works), Space dives over a rail, F at the wheel drives (and stands you back up inside), boxes open on the PACK screen, beds sleep (N), the RV makes camp when parked (stove, water tank). One RV stands in the south flats at (120, 290).
- Entity ids: characters `c<N>`, vehicles `v<N>`. The player is `c1` (or `player`). Named NPCs also answer to their npc id (`okonkwo`, `reyes`, `ike`, `kenji`, `mags`, `saoirse`, `tomas`, `vo`) or their full name. `id=hostile` resolves to the nearest enemy.
- World map: `node tools/dl.mjs map`. Roads run every 80 m on −320..320. Route 66 is `z=0` and crosses the whole map. Rust Haven (walled town) is `|x|,|z| < 88`, Phoenix ruins are out to ~250, and beyond that is the Glass Flats desert, where the 6 raider camps sit.
- **Past the island: the streamed world** (`world`, `chunk`, `locate`; docs/design/WEB_STREAMING.md). The map above is THE ISLAND, `|x|,|z| ≤ 464`, unchanged and never walled now. Outside it the world is streamed from the usmap rows in 256 m chunks (`chunk (cx, cz)` covers `[cx·256, cx·256+256)`): a usmap point `u` sits at `(u − PHX) · K` with `PHX = (−43250, 7250)` and `K = 5.2` (`src/data/streaming.js`), so Phoenix is the origin. Route 66 leaves the island at both ends and becomes **I-10**: west to **Los Angeles** (`teleport town=losangeles`, about 42 km), east toward **El Paso**; exits where the rows put them (`locate name="exit 4"`), signs in game miles counted from Los Angeles (1 mile = 1,609 m of built road; Phoenix is mile 26.3; `teleport mile=30 dir=east` puts you in the eastbound lanes at mile 30, facing east). A soft **dust wall** 45 km from Phoenix turns you back. Streamed ground is flat for gameplay except ramps, fills and bridge decks (`heightAt(x, z, y)`); mesas and wrecks are solid. `path`, `moveTo` and `drive x z` lay out the ground between their ends first (a `query` stall) and reach one nav window (1 km) at most; farther, they say so (the road graph is P3). Out on the corridor only the Phoenix ring's containers persist across a save.
- **The Phoenix ring** (`ring`; docs/design/WEB_STREAMING.md §1.3; rows in `src/data/ring.js`, built by `src/world/ring.js`): round the island, past its glass flats, a dead city of about 2,400 walk-in buildings out to a lobed edge near 1.5 km, streamed like any chunk. Its streets are the island's own lattice carried outward (a 14 m road on every multiple of 80 m, 20 m arterials on multiples of 320), starting with a road that hugs the island 16 m off its edge. I-10 runs through it as the city freeway: local streets stop short of it and arterials cross it at grade. Zones: THE STRIP on the freeway and some arterials (strip malls, fuel stops, diners), THE YARDS along the Iron Line (x = -360, dead track and boxcars) and the old river's wash to the north-east, THE DEAD HOUSES everywhere else, and THE BURN, the ruins thinning out over the last 200 m. Every building is a shell you walk into through a door gap facing its street: window holes that sight and rounds pass, a floor, a roof that hides while you are inside, and a real floor plan (`src/world/floorplan.js`, rows in `src/data/floorplans.js`, docs/design/WEB_FLOORPLANS.md): a house opens into its living room with the kitchen beside it and two or three bedrooms and a bathroom down a short hall; a duplex is two one-bedroom flats; a workshop, diner, fuel stop or mall unit has its floor out front and a stock room, kitchen, office and restroom behind; every room furnished as what it is (bed, nightstand and dresser; couch, armchair, rug and TV; fridge, stove, sink and cupboards; tub, toilet and medicine cabinet; booths in a diner) and floored to match (carpet, linoleum, tile). Its shelves, crates, racks, counters, cupboards, fridges, dressers, desks and cabinets are PACK-screen containers rolling their room's table (ids from their position, loot from their id's seed, registered only while their chunk is hot, what you took kept while it is away and in a save), and its beds can be slept in. No door leaves, locks or glass out here yet (the island's `interiors.js` stays on the island). **People live there** (`residents`; R2, §1.3): scavenger families in the dead houses (a bed each, out on runs by day, home by dark), squatters behind a boarded-up shop front on THE STRIP, a Dustwolf chop shop in each quarter of THE YARDS, an infected nest in THE BURN that holes up somewhere new most dawns with an Echo at its boards. They are records keyed by building, promoted within 210 m of you and written back when you leave; a family's shelves are theirs (taking is a `steal` they witness), and a death, a grudge, a body's contents last across the chunk going and a save. They take only free character slots and yield first when anyone else needs one. Traffic is R3.
- **Florida** (`region`; docs/design/WEB_FLORIDA.md): a second streamed region on the same plane and K, 222 km east of Phoenix (world x 187-233 km, z 22-78 km). I-95 runs north from Miami up the Atlantic side (exits by milepost: MERIDIAN is exit 9), I-75 west from Miami across ALLIGATOR ALLEY to Tampa; swamp, flatwoods, a barrier island and lagoon, canals and sloughs (`world/regions.js` is the water authority past the island: wade, swim, flood). MERIDIAN is a walled holdout of walk-in planned buildings (clinic and clone bay, sheriff, store, gunsmith, water, cantina, garage...) with its own people. THE SQUALL LINE holds you inside the box as the dust wall does. Players start there; the harness starts in Phoenix unless `?start=florida`.
- Set-pieces beyond the grid: **mesas/buttes/ridges** ring the desert at 350–440 m (solid, routed around). The **river** runs north–south on the east edge (x≈410–428) into **the lake** (390, 398, 7 m deep) with a **dock** at (360, 382) and the **Route 66 bridge** at x=416. The **Iron Line** railway runs north–south at **x=−360**: Dust Bowl Station at z=110, a level crossing on Route 66 (z=0). A freight (`train`) cycles every couple of minutes; **Dustwolf convoys** (`convoy`) cross on Route 66 every ~3–5 minutes.
- Jumps (`stunts`, rows in `src/data/stunts.js`): **the Thrill Show** in the open strip east of the x=320 road, just south of Route 66 (x 330–400, z 13–76): **Wreck Row** (z=28, a steel kicker, five wrecks side by side, a landing deck 25 m on; ~40 mph at the lip lands clean), **the Table** (z=58) and **the Whoops** (z=70), bleachers, whitewashed-stone letters. **The Dunes** in the south-west Glass Flats (x −310..−250, z 250..310): wind-built mounds with slip faces to the east. `stunts run=wreckrow speed=18` drives a car at a jump and reports the landing.
- The military (`base`, rows in `src/data/bases.js`, docs/design/WEB_MILITARY.md): **OUTPOST NINE**, the Federal Remnant's fenced post in the north-west Glass Flats, fence x −324..−260, z −427..−367, the gate at x −304 on its south run, a gravel spur north from DEAD MAN RD (z −320). Twelve soldiers (the gate, two doors, the motor pool, four tower decks, three on patrol), a locked steel armory door, a PATROL TRUCK and an ARMORED CARRIER in the motor pool. Walk in and a sentry warns you once; stay six seconds or fire a shot and the post opens fire (a Remnant-friendly player is waved through).

## Time, determinism & hidden tabs

- The realtime loop runs on `requestAnimationFrame`, which **stops when the tab is hidden**. Agents should advance the sim with **`step seconds=N`**: fixed 60 Hz, it runs in any tab state and returns the new state plus the events that happened.
- `moveTo`, `fire`, `drive` and `harpoon` step the sim internally, so they're blocking actions that return outcomes.
- `screenshot` renders at a fixed 1280×720 regardless of window size. It captures the world only; the DOM HUD isn't in it. To see the HUD, use a real browser screenshot.
- Randomness: world layout and initial population are seeded (identical every boot). Combat spread and AI choices use `Math.random`.

## Invariants (don't break these)

1. **Performance budget: under 150 draw calls** for the whole scene (currently ~50–80). Anything with more than a handful of copies goes in an `InstancedMesh` or gets merged (`mergeGeometries`). Never create a `Mesh` per bullet, particle, decal or character. Check with `node tools/dl.mjs perf` and `scenario name=stress`.
2. **No per-frame allocation in hot loops.** Reuse module-level `Vector3`/`Matrix4`/`Object3D` scratch objects, as the existing systems do.
3. **Fixed light count.** Dynamic lights come from the 4 pooled point lights in `fx.js`. Adding or removing lights at runtime recompiles every shader. Fake light with additive ground decals (`radialGlow`, `coneTexture`), the way lamps and headlights do.
4. **Every new command goes in `COMMANDS`** with `group`, `desc` and `args`. It must return plain JSON and use `need()` for errors with a useful message. Then regenerate `docs/COMMANDS.md`.
5. **Content as data.** New weapons, vehicles, NPCs and weather are rows in their tables or JSON packs, not new code paths.
6. **Art direction:** dusty post-apocalyptic palette (rust, sand, bone, gold). **Never purple** (hues ~270–320 are banned). Every person shown in UI (portraits, dialogue) shows their **country flag** as a real drawing (`ui/portrait.js` `FLAGS`), never emoji letters.
7. **Run `node tools/dl.mjs selftest` after engine changes.** It must stay green. Add a check there when you add a system.
8. **IP hygiene: borrow mechanics, never names.** The game is fan service for GTA2, Autoduel, Project Zomboid, We're Alive, 28 Days Later and the Deathlands novels, so their verbs, loops and genre shapes are fair game; their titles, coined slang, characters and catchphrases are not. `node tools/ip-lint.mjs` scans every player-facing string and must report **0 deny** before a commit. A deliberate exception goes in `tools/ip-allow.json` with a reason. Canon names come from `docs/DIVIDED_STATES.md` (scrip, holdouts, Carousel Stations, the 50 rulers).
9. **The island is golden.** The streamed world never changes Phoenix: `world` must report `islandMatches: true` (its hash of the island's boxes and buildings equals `src/data/golden.json`). A change to `world/city.js` that moves the island on purpose updates the golden in the same commit. Streamed content is a pure function of the data: same chunk, same hash, sliced or sync.
